Support

Version / effective date: 2026-10-12

Contact support

Email nariyirm@gmail.com. Include your app version, iPhone/iPad model, iOS version and a description of the issue. Screenshots are optional; remove personal information. Never send your device credential, invite code or recovery code. KitchMemo is operated by Haoxuan Sun.

Start using the app

Complete the opening guide, open Fridge and add an item manually or choose a barcode/photo option. Confirm the name, quantity, storage and package dates before saving. Internet access is required for server-backed features.

Reminders

Enable notifications in Profile and in iOS Settings if you want system reminders. Quiet hours and per-device preferences affect delivery. Reminder delivery is best effort; check food labels and your inventory directly.

Shared fridge

Use the sharing control in Fridge to create or join a shared space. Only share invitation codes with intended household members. Members see shared stock and shopping activity; personal learning and private chats remain private.

Restore your identity

Generate and keep a recovery code under Profile → Device recovery before changing devices. Recovery codes are one-time; save the replacement code after a successful recovery. Deleted identities and expired/used recovery codes cannot restore erased data.

AI permission and food safety

Optional AI features require consent under Profile → Privacy. You can withdraw permission and continue using manual features. Recognition supports a limited food set and provides suggestions, not a food-safety assessment. Check and edit every suggestion before saving.

Delete data

Use Profile → Privacy → Delete my data. This also removes your contributions from a shared fridge; other members’ entries remain. Read the in-app confirmation and privacy policy before proceeding. You can explicitly start again with a new empty identity afterward.
