# Kitchen hero generation

Generated using the built-in imagegen tool, using `design-preview-v1.png` as the reference. Output retained at `source-assets/kitchen-hero.png` and embedded in `index.html` as optimized WebP.

## Prompt

Use case: background-extraction. Create the standalone HERO ART asset for implementing the approved KitchMemo HTML webpage shown in reference image 1. Extract and faithfully reconstruct ONLY the isometric miniature kitchen from the TOP RIGHT hero of that webpage. It has warm coral-orange cabinets, cream refrigerator at the right, oven and stove, sink under left window, tiny wood island with stools and vegetables, trailing plants, soft warm lighting. Preserve the composition, style, colors, camera angle and cute high-quality 3D materiality as closely as possible to the approved hero. Output a wide landscape image around 1536x1024 with the ENTIRE kitchen object visible, comfortable transparent margin around it. Background must be genuinely transparent alpha. NO webpage, NO text, NO logos, NO mascot, NO labels, NO buttons, NO UI, NO shadow blobs beyond subtle contact shadow directly under the kitchen. This asset is a decorative illustration, not a screenshot.
