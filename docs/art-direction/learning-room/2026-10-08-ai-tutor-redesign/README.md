## 当前问题与设计方向

当前判断基于 LearningTutorPanel.tsx、LearningTutorController.tsx 的组件结构和已批准学堂效果图；不是当前运行版真机截图审核。

- 顶部历史、新对话、设置与当前课程混在同一层级，主次关系弱。
- 空会话缺少明确起点；解释、简化、举例以普通链接形式出现。
- 长回答、技术版本信息、来源和反馈连续堆叠，学习内容缺乏阅读节奏。
- 主动帮助和复习推荐主要是普通文字／链接，Spoonie 的陪伴关系不突出。

推荐方向：**Spoonie 伴学 · 温暖、安静、内容清晰**。保持薄荷绿／森林绿／橙色品牌体系、原 Spoonie 和 SDG 13／13.3，重点改善导师的入口、讲解和课程内提示，不重构冰箱、成就或整个学堂导航。

## 落地时保留的行为

- 学习会话与偏好继续归个人 learner；保留双语、历史、新会话、设置、反馈、删除／清除和恢复。
- 历史／设置收进右上菜单；会话管理及破坏性操作保留原确认流程。
- 来源折叠只减少视觉密度，展开仍显示真实机构、标题、日期、地区与外链。内容版本信息如需展示，进入会话详情，不占据主要回答区域。
- 已答正式题只保留解释／简化／举例，不能添加自由输入或借此读取未答正式题答案。
- 正式首答、评分、升级仍归服务端；活动正式测验期间维持原全局限制。未答正式题不出现导师入口。
- 主动提示沿用原服务端资格、限频、冷却和偏好开关；停留实验、读屏／视频排除仍按原规则。
- 课程展示的 SDG 图标落地时使用项目官方资产，不能采用效果图生成的近似图标。
- UI 不要求 AI 回答必须提供标题或插图；真实响应没有结构时保持可读的原文本，不由前端补造事实。

已逐张目视检查：四张为同一品牌／设备／中文字体方向；主要文案可读；课程与导师层次、答后状态和主动帮助拒绝入口可识别。

2. 01／03 的角色在生成图中略大，窄屏或字体放大时优先缩小角色，给学习内容留空间。
3. 调整 01／02 橙色发送按钮上的白色箭头，采用可读前景色；核验全套真实 token 对比度。
4. 覆盖长回答、长题干、键盘展开、历史、设置、加载／失败／断网、限制状态和 1.3／1.6 字体。
