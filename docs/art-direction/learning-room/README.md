# Learning Room design direction

Current concept: [2026-10-05 app palette v2](2026-10-05-app-palette-v2/README.md).

The user approved v2 for strict implementation. Start future implementation from [the handoff](../../learning-room/HANDOFF.md), [the detailed plan](../../learning-room/IMPLEMENTATION_PLAN.md), and [the actual status](../../learning-room/IMPLEMENTATION_STATUS.md).

The project's confirmed UN alignment is **SDG 13 — Climate Action**. The learning room focuses on waste and climate education, with SDG 13.3 as its most direct educational connection. Its palette must match the current Fridge and Achievements screens.

The earlier Apple concept folder is retained as visual exploration history. Its SDG 12 imagery is superseded by v2; do not use those images as the current product specification.
