# 冰箱快速使用验证

日期：2026-10-07

## 实现范围

食材卡片增加独立“使用”按钮。快速使用面板沿用详情编辑面板的浅灰白底、蓝色数量控件与橙色确认按钮，支持增减数量、选择全部用完、预览剩余库存、确认后刷新库存和补货状态。

复用现有库存数量接口及版本检查，没有修改数据库或 API 契约。

## 自动检查

- `npx tsc --noEmit`：通过。
- `node scripts/test-inventory-quick-use.mjs`：10 项通过，覆盖直接输入、大容量及三位小数、非法格式、各单位步长、小数扣减、最后不足一个步长的库存、非法数量、不可变快照更新、用完移除、版本保护及按名称和单位汇总补货状态。
- `git diff --check`：通过。
- `npx expo export --platform android --output-dir output/quick-use-android --no-bytecode`：通过，Android bundle 成功生成。
- 直接输入改进后，`npx expo export --platform android --output-dir output/quick-use-input-android --no-bytecode`：通过。

## 浏览器组件检查

使用真实 `FridgeFoodCard`、`InventoryQuickUseSheet` 和双语文案，API 通过本地内存 fixture 模拟。没有写入远端库存。

| 场景 | 结果 |
| --- | --- |
| 点击使用 | 只打开使用面板，没有触发详情或库存请求 |
| 数量增减、关闭 | 正确预览剩余量；关闭不提交 |
| 部分使用 | 6 个使用 1 个，确认后剩余 5 个，提交一次 |
| 全部用完 | 选择本身不提交；确认后批次从列表移除 |
| 共享版本冲突 | 重读最新库存，显示提醒，需再次明确确认 |
| 网络失败 | 保留数量和错误提示，可重试 |
| 连续点击确认 | 慢请求期间禁用操作，只提交一次 |
| 超过 use-by | 禁止确认及全部用完，不发送请求 |
| 小数容量 | 0.3 L 使用 0.1 L，剩余 0.2 L |
| 390 × 844 中文 | 面板布局正常 |
| 320 × 568 英文 | 剩余提示和固定底部操作完整显示 |
| 直接输入 1000 ml | 1500 ml 库存预览剩余 500 ml，确认后只提交一次并显示 500 ml |
| 输入 1501 ml、清空 | 显示对应校验提示，确认禁用；全部用完可以恢复有效数量 |
| 自定义 75 ml 按减号 | 按 50 ml 步长变成 25 ml，不强制对齐到步长 |
| 自定义 250 g 按加号 | 按 50 g 步长变成 300 g，预览正确 |
| 自定义 0.075 kg | 低于 0.1 kg 步长仍可提交，1 kg 库存剩余 0.925 kg |
| 320 × 350 可用高度 | 聚焦输入后滚动至数量和剩余库存；操作并排显示 |
